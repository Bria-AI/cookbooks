# # Bria Cookbooks

## Overview
This repository contains a collection of scripts, tutorials, and best practices for working with generative AI models, specifically tailored for Bria AI's workflows.  
It provides **ready-to-use scripts**, **detailed tutorials**, and **structured pipelines** to help engineers and researchers efficiently work with AI models.

## Table of Contents
- [Usage](#usage)
- [Tutorials](#tutorials)
- [Additional Resources](#additional-resources)

## Usage
Each directory in this repository is structured to serve a different purpose:

- **`examples/`** – Minimal, ready-to-run code snippets that showcase model capabilities and basic use cases.  
- **`pipelines/`** – Structured workflows and collections of scripts designed for more complex tasks, such as **data preparation**, **model fine-tuning**, and **batch processing**.
