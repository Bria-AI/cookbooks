# # Bria Cookbooks

## Overview
This repository contains a collection of scripts, tutorials, and best practices for working with generative AI models, specifically tailored for Bria AI's workflows.  
It provides **ready-to-use scripts**, **detailed tutorials**, and **structured pipelines** to help engineers and researchers efficiently work with AI models.



- **`examples/`** – Structured workflows and collections of scripts designed for more complex tasks, such as **data preparation**, **model fine-tuning**, and **batch processing**.  
- **`Tutorials/`** – We provide in-depth tutorials on various aspects of generative AI, covering both theoretical and practical implementations
